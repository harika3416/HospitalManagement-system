# Hospital Management System

A Java-based web application developed for managing hospital operations such as patient records, doctor details, and appointment booking.

## Features

* Patient Registration
* Doctor Listing
* Appointment Booking
* Patient Record Management
* Database Connectivity
* Frontend and Backend Integration

## Technologies Used

* Java
* JSP
* Servlets
* MySQL
* HTML
* CSS
* Bootstrap

## Tools & Software

* Eclipse IDE
* Apache Tomcat
* MySQL Workbench

## Project Description

This project was developed to simplify hospital management processes by integrating frontend interfaces with backend database operations. It enables efficient handling of patient and doctor information through a web-based system.
